Today I want to explain AI agents in simple terms, show what I have built with them, and suggest how we could use them in HR.

An AI that gets things done

Normal AI answers your question.

An AI agent takes a goal, works on it step by step, uses tools, and checks its own result.

Think of it as an AI employee, not an AI search box.

A chatbot answers and stops. An agent gets a goal and loops: plan, act with tools, check the result, improve, until the job is done.

Chat AI vs AI Agent

LLM / Chat AI The brain ChatGPT · Claude · Gemini
01You ask a question
02It gives an answer
03It stops and waits
AI Agent Brain + hands + a schedule Hermes · Claude Code · Codex
01You give it a goal
02It plans and does the work
03It reports back when done
LLM=the brain. Agent=brain + hands + a schedule.
ChatGPT, Claude and Gemini are the brains. An agent like Hermes, Claude Code or Codex wraps a brain with tools and a schedule, so it can actually do the work.

What an agent can do that chat can’t

Works on a scheduleRuns tasks at set times, without being asked
Uses toolsBrowses the web, edits files, runs apps
Thinks in stepsBreaks a goal into steps and decides what’s next
Has a personaA fixed role, tone and set of rules
Learns skillsInstall new abilities, like apps on a phone
Works in a teamHands work to other agents in a workflow
These six things separate an agent from a chatbot: schedules, tools, step-by-step thinking, a persona, installable skills, and teamwork with other agents.

What every agent is made of

Who it is
Soul Personality, role and rules, written in one file
What it can do
Skills Step-by-step playbooks and tools it can use
What it remembers
Memory Notes about you, your work and past tasks
ModelThe brain underneath
Picked per job: a small, fast model for simple tasks, a stronger one for judgment and creative work.
An agent is a model plus three things. The model is the brain, and you choose it per job: cheap and fast for simple work, stronger for judgment. Soul is its character and job description, Skills are its playbooks, Memory is its experience with you.

Dojima

A trading-practice web app I built with Claude Code, without writing the code myself.

Dojima is a full trading-practice app with paper money. I am not a programmer: I describe what I want, Claude Code (an AI agent) writes the code and publishes it. It has a frontend you see, a backend that runs the logic, and a database that stores the data.
